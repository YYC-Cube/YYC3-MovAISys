1. **降低AI接入门槛**：让任何项目都能快速接入AI能力

#### 8.2.2 快速接入示例

**示例1：智能客服**

```typescript
import { UnifiedAIInterface } from '@yyc3/ai-sdk';

class IntelligentCustomerService {
  private ai: UnifiedAIInterface;
  
  constructor() {
    this.ai = new UnifiedAIInterface({
      apiKey: process.env.AI_API_KEY
    });
  }
  
  async handleCustomerQuery(query: string): Promise<string> {
    const response = await this.ai.chat([
      { 
        role: 'system', 
        content: '你是一个专业的客服代表，请友好地回答用户问题' 
      },
      { role: 'user', content: query }
    ]);
    
    return response.content;
  }
}

// 使用
const service = new IntelligentCustomerService();
const answer = await service.handleCustomerQuery('如何退款？');
console.log(answer);
```
